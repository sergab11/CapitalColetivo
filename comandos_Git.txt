Para realizar mudanças no Repositório e colocar no master:
1) git add .
2) git commit -a -m "mensagem do commit"
3) git push --set-upstream origin master

Para "pegar" atualizações do Repositório do master:
1) git pull origin master

Para iniciar um repositório em uma pasta local e adicionar
uma origem remota ao mesmo:
1) git init
2) git remote add origin <link do repositório>
